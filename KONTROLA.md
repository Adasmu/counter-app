# Ruční kontrola před odevzdáním

Políčka nejsou předem zaškrtnutá. Označ je až po skutečném ověření.

- [ ] `node --version` vypisuje v26 a `npm --version` řadu 11.
- [ ] `npm install` skončilo bez chyby a vznikl `package-lock.json`.
- [ ] Autor i varianta odpovídají mému jménu a přesnému univerzitnímu e-mailu.
- [ ] Počítadlo bez názvu ani s mezerami nejde uložit.
- [ ] Funguje +1, -1 a reset; základní počítadlo neklesne pod nulu.
- [ ] Uložení vynuluje formulář a zobrazí toast.
- [ ] Historie zobrazuje název, hodnotu, čas a správný součet všech záznamů.
- [ ] Záznamy zůstanou po obnovení stránky na stejné adrese.
- [ ] Funguje hledání, všech šest řazení a stav bez výsledků hledání.
- [ ] Varianta A/B/C/D reaguje na přidání i odstranění záznamu.
- [ ] Odstranění jedné položky neovlivní ostatní a zobrazí toast.
- [ ] Zrušení dialogu Vymazat vše nemaže data; potvrzení je smaže.
- [ ] Celá historie se smaže i při aktivním vyhledávání nebo filtru.
- [ ] Dialog lze otevřít znovu; po smazání a obnovení se záznamy nevrátí.
- [ ] Prázdná historie nezobrazuje NaN ani Infinity.
- [ ] Aplikace funguje i na úzkém mobilním zobrazení a konzole neobsahuje neočekávané chyby.
- [ ] `npm run lint`, `npm test -- --watch=false` a `npx ionic build` skončily bez chyby.
- [ ] `npm run ready` skončilo bez chyby.
- [ ] Rozumím toku dat a umím provést drobnou úpravu.
- [ ] Použití asistence je v souladu s pravidly kurzu.
- [ ] Veřejný repozitář obsahuje lockfile a alespoň čtyři smysluplné commity.
- [ ] Repozitář lze otevřít bez přihlášení a odevzdáno bylo jeho URL.
